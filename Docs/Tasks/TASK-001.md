# TASK-001 Player Movement

## Objective
プレイヤーオブジェクトを左右に移動できるようにする。

## Requirements
- Aキーまたは左矢印キーで左へ移動する
- Dキーまたは右矢印キーで右へ移動する
- 移動速度はInspectorから設定可能にする
- Time.deltaTimeを使用する
- Y座標とZ座標は変更しない

## Allowed Files
新規作成:
Assets/Scripts/Player/PlayerMovement.cs

## Restrictions
- Sceneを変更しない
- Prefabを変更しない
- ProjectSettingsを変更しない
- 他のスクリプトを変更しない

## Completion Criteria
- PlayerMovement.csが作成されている
- Unity上でコンパイルエラーが発生しない
- 指定された左右移動処理が実装されている
