# Project Overview

## Project Name
Unity AI Agent Sandbox

## Purpose
CodexおよびGemma 4を利用したUnityゲーム開発自動化基盤を検証する。

## Environment
- Unity
- C#
- Git
- GitHub
- Codex
- Gemma 4

## Development Policy
AIがコード編集と自動テストを担当し、
ユーザーがUnity Editor上での動作確認、デバッグ判断、仕様改善を担当する。
